Sintec.PDF portable mode

While this file sits next to sintec-pdf.exe, Sintec.PDF keeps its settings, log files, crash-recovery
autosaves and new digital IDs in the PdfCraftData folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Sintec.PDF with its settings.

Delete this file to use the normal per-user folders (%APPDATA%\Sintec.PDF and
%LOCALAPPDATA%\Sintec.PDF) instead. If PdfCraftData can't be written (for example on a read-only
drive), Sintec.PDF says so and uses the per-user folders instead.
