Goal: Sintec.PDF 0.3.0 builds, tests and ships for Linux x86_64 (and aarch64 if the runner is cheap) next to Windows and macOS. Upstream PdfCraft has Linux/AppImage/deb/rpm/Flatpak packaging; our fork removed those workflows (see docs/releasing.md header), packaging scripts are kept in packaging/linux as reference.
1. Audit: build the workspace for x86_64-unknown-linux-gnu (use `cargo check --target ...` if a cross target is installable on this Windows box, otherwise read the code) and list everything that is Windows/macOS-only in OUR additions: tab tear-off as separate process (tear_off.rs, doc_windows.rs, drag_pointer.rs), scanner (scan_ui.rs, Windows WIA/TWAIN? choose SANE on Linux or hide the command with a clear message), print path (crates/print uses CUPS on non-Windows - verify our 009/012 print options and paper-fit setting work there), bundled fonts, update checks, MSI-only things, file_watch, desktop_theme, staging. For each: works / needs cfg / needs a Linux implementation.
2. Add `.github/workflows` jobs: ci.yml `linux` job (ubuntu-latest: apt deps for egui/winit/wayland/x11/xkbcommon/fontconfig/CUPS headers, fmt, clippy -D warnings, cargo test --workspace headless via xvfb where needed) and release.yml `linux` job producing `sintec-pdf-<version>-linux-x86_64.AppImage` + `.deb` (+ tar.gz of CLI), included in the draft release and SHA256SUMS.txt. Reuse packaging/linux scripts, rebranded to Sintec.PDF (icons, desktop file, MIME type application/pdf, app id). Update docs/releasing.md and README platform list.
3. Fix compile/test failures on Linux that you can find by reading; guard Windows-only code with cfg. Do NOT change Windows/macOS behaviour.
4. Report: what is done, what could not be verified without a Linux runner (CI will tell), and what remains for a first Linux release (e.g. SANE scanning, Wayland tear-off).
Constraints: pure additive for other platforms; never-panic rules; Sintec branding; en+ru only. Done when fmt, clippy and tests are green locally for the host and the workflow YAML is valid (actionlint if available).
