Problem: in Edit PDF, dragging a paragraph box's left/right width handle shows the box resizing, but on release it jumps back to the old size, so the width change looks like it did nothing. Repro file: C:\Users\kochurin.a\Downloads\МаляковАА.pdf (table-like page; many single-line / single-word cells; data is not sensitive). Copy it into a test fixture if useful.

Findings (already investigated):
- crates/ui-egui/src/edit_text_ui.rs ~L785-815: on release a resize sends Edit::EditTextBlock{text: l.text, style: BlockStyle{width: Some(w), offset}}. The block rect is then read back as the text's real extent (comment 'Intended' ~L795), so the box returns to the text size.
- Narrowing works for multi-word cells (rewrap via crates/edit/src/text.rs rewrite_block). Widening changes nothing: crates/edit/src/text_regions.rs:244-247 uses block.editor_text with hard row breaks when text == block.text, so rows never merge; single-line/left-aligned text has no visible change. Single-word cells cannot narrow at all.
- Earlier tasks 011/013 touched the same handles; do not regress them.

Goal: after a width drag, the result must be visible and stable. Decide a sensible design, e.g. keep the user-set box width for that paragraph (UI-side, per page/block, dropped when the document changes or the paragraph is edited) so the box stays at the dragged width, and make rewrap use it; narrowing below the longest word must clamp and the box should show the clamped width instead of snapping to something unexpected. Do not merge separate table rows/cells into one paragraph. Features otherwise unchanged; default behaviour of text editing unchanged.

Done when: regression tests (ui-egui tests and/or crates/edit tests) cover: widen a single-line box and it stays wide after release; narrow a multi-word cell and it stays narrow and rewrapped; single-word cell clamps; test on МаляковАА.pdf blocks (e.g. 'Доступ к сети Московского офиса', 'имя входа (login)'). cargo fmt, clippy and cargo test green. Write what you changed and the design decision in the report.
