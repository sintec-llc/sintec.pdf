Goals:
1. Detect for each text run: family guess, weight (regular/bold/semibold from FontDescriptor Flags/StemV/FontWeight/ForceBold, the BaseFont name suffix like -Bold/Bold/Black, and glyph-width/stem analysis for anonymised subset fonts), italic/oblique (ItalicAngle, Flags, name), size (Tf size times text matrix scale, so effective size), fill colour; show them in the text panel and apply them automatically on the new text.
2. Missing glyphs: when the embedded subset lacks a character, choose the substitute by the detected family+weight+style (bundled metric-compatible fonts, Arial->Liberation Sans/Arimo, Times->Tinos etc., a Bold/Italic variant when needed; synthesize bold by stroke/embolden only if no bold face exists), scale it so x-height/cap-height and advance widths match the original, and keep the original font for the glyphs it has. Prefer re-using the embedded font for existing glyphs; for the whole edited run prefer one consistent substitute rather than mixing when mixing looks worse (decide by test on the repro file and report).
3. Make the choice explainable: tooltip/status in the text panel "installed / substitute: X (bold)" so the user can override family/weight/style manually.
4. Tests: unit tests for weight/style detection (name suffixes, flags, widths), for fallback selection (bold heading -> bold substitute), and a regression test with a synthetic PDF with a bold subset font where an added Cyrillic letter must come out bold with matching height. Verify on the real repro file by rendering before/after and compare visually (save PNGs to a temp dir, describe in the report).
Constraints: never-panic rules, en+ru strings (ru.tsv rules as in task 024 incl. zz_rehash.py), Sintec branding. Done when fmt, clippy -D warnings and cargo test for touched crates are green. Report what is detected, how, and what is still imperfect.
