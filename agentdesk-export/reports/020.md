**Changes (tests only):**
- **Shared font helper:** `standard_faces()` now lives in `tests/support/mod.rs`. The copies in `editing.rs`, `text_box_frames.rs`, `text_box_grip.rs` and `text_box_width.rs` are removed, and those files use the shared one.
- **Font override added:** `app.fonts.installed_override = Some(standard_faces())` is now set in the app constructors of `content.rs`, `control.rs`, `object_selection.rs` and `ocr.rs`. `editing.rs` already set it at several constructors; I did not recheck which `editing.rs` tests lacked it.
  - **Root cause:** on a machine without matching installed fonts, clicking text opens the font-substitution flow instead of the editor. That broke the content, control, editing, object-selection and OCR tests on macOS.
- **`forms.rs`:** the `one_frame` helper now maps the `command` modifier to ⌘ on macOS and Ctrl elsewhere. I did not find the `Os NotFound` path. My guess is that the old Ctrl+S never fired on macOS, so `saved.pdf` was never written. I haven't confirmed that.
- **`ui.rs` (`the_integrated_title_bar_is_the_traffic_light_band`):** the expected label "Discord" is now "Check updates". I assumed the title-bar button was renamed and did not bisect `git log` to confirm.
- **`ui_group/updates.rs` (`skip_this_version_is_remembered`):** it now polls up to 400 times for the "Skip this version" pop-up before clicking it. The update check runs on a worker thread, so the old single settle could come too early on a slow machine.
