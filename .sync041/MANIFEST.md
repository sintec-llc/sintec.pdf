# .sync041: our versions of files taken from upstream in the 041 merge

Task 041 merged upstream PdfCraft `d749fd806` (report 040 pin). In the feature zones (optimize,
engine, export, edit, print, ui-egui, apps/pdfcraft/src, automation, i18n) the merge took
**upstream's** files; our version of every file we had changed since the last sync (v0.9.0,
`645016add`) is kept here at `ours/<path>`, byte for byte as on `feature/0.2.6` (`4a105342e`).
Files only we had (new modules, tests, fixtures) were removed from the tree and live only here.
Re-apply each feature on top of upstream's code, then delete its files here.

Features are the sections of `reports/038.md` (on branch `auto/038`). "Commits" are our commit
subjects touching the file since v0.9.0 (newest first, at most three).

Not stashed because they were resolved in place:
- `crates/ocr`: upstream's crate, with our PP-OCRv5 engine (`paddle.rs`) added as a `Recognizer`
  (`PaddleRecognizer`, `Script`, `PaddleModels`, `ALL_LANGUAGES`) and wired into
  `crates/engine/src/ocr.rs` (`paddle_engine`); our old `lib.rs`/`Cargo.toml` are here for reference.
- `crates/cos`: `SaveOptions::best_compression` and `Stream::flate_best` kept (feature 4 needs them).
- `crates/create`: our `picture.rs` (signature pictures) and `unicode_text.rs` kept beside upstream's modules.
- `ATTRIBUTION.toml`: ours plus upstream's new records; the `ru.tsv` record was dropped with the file
  (it is here, see feature 5).
